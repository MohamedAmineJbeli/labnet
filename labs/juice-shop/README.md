# OWASP Juice Shop

OWASP Juice Shop is an intentionally insecure web application used for security training. It contains challenges covering injection, broken authentication, access control, XSS, and other vulnerability classes.

Official Repository: https://github.com/juice-shop/juice-shop

## LabNet Implementation
This scenario uses the official Docker image, pinned to `v20.3.0`. It is bound to `127.0.0.1:3000` to prevent accidental exposure to the local network during testing.
