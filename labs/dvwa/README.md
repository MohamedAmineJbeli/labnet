# DVWA (Damn Vulnerable Web Application)

DVWA is a PHP/MySQL web application that is deliberately vulnerable. Its goal is to aid security professionals test their skills and tools in a legal environment.

Official Repository: https://github.com/digininja/DVWA

## LabNet Implementation
This scenario utilizes the official Docker image. It is bound to `127.0.0.1` to prevent accidental exposure to the local network during testing.
